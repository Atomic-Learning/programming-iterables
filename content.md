# What Is an Iterable?

An iterable is an object that can provide values one at a time in a sequence.  These values may be stored as part of the iterable's internal structure, or generated on-demand as they are requested. A list is an example of an iterable and will provide each entry of the list in order. A string is another example, and will typically provide each character in order.

# Why Iterables Matter

Iterables are the foundation of loop-based processing as they provide a sequence of values that can be processed one at a time. This is useful whenever you need to analyse, transform, or filter many values in a similar way.
